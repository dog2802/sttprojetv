# STTProjetV

Голосовой ввод текста для Windows: зажал хоткей — сказал фразу — отпустил — готовый текст
(с пунктуацией и без опечаток) уже лежит в буфере обмена. Сделано для текстовых РП-игр вроде
SS14, где нужно быстро печатать реплики и игровые термины (названия медикаментов и т.п.),
которых нет в обычных словарях распознавания речи.

Аналог закрывшегося Laitis, но только функция "голос → текст", без голосовых команд управления
компьютером.

## Возможности

- **Push-to-talk** — зажал хоткей (клавиатура или боковая кнопка мыши), сказал фразу, отпустил.
  Whisper обрабатывает её целиком, поэтому пунктуация получается правильной.
- **Локальное распознавание** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper)
  (модель `large-v3-turbo` по умолчанию), работает полностью офлайн, без ключей и подписок.
- **Автоопределение железа** — при первом запуске сама решает: GPU + `large-v3-turbo`, если
  есть поддерживаемая видеокарта NVIDIA, иначе CPU + модель полегче. Можно переопределить
  вручную в настройках.
- **Модульные словари терминов без кода** — свои слова (названия медикаментов, предметов,
  локаций и т.п.) добавляются прямо в окне настроек или текстовым файлом в папке
  `dictionaries/` — каждый `.txt` файл там - отдельный именованный список (например
  `ss14.txt`, `другая-игра.txt`), между ними можно переключаться в выпадающем списке в
  настройках. Активный словарь перечитывается перед каждой фразой, поэтому и правки внутри
  списка, и переключение между списками применяются сразу, без перезапуска. Распознанный текст
  сверяется со словарём (нечёткое сравнение, rapidfuzz) и похожие искажения заменяются на
  точную форму термина.
- **Трей + окно настроек** — иконка показывает статус (ожидание/запись/распознаю), из меню
  открывается окно настроек: словарь терминов, микрофон, хоткей (в т.ч. запись нажатием),
  модель Whisper, режим вставки текста. Все изменения применяются сразу, без перезапуска
  программы.
- **Буфер обмена или прямая вставка** — по умолчанию текст просто копируется в буфер, опционально
  можно включить автоматическую вставку в активное окно.

## Установка и запуск из исходников

Требуется Python 3.11+.

```bash
python -m venv .venv
.venv\Scripts\activate
```

**Если у вас видеокарта NVIDIA** — сначала поставьте CUDA-сборку torch (обычный
`pip install torch` ставит CPU-версию, и распознавание будет работать в 15-20 раз медленнее,
даже если видеокарта есть):

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu126
```

Затем (в любом случае, с GPU или без):

```bash
pip install -r requirements.txt
python -m sttprojetv
```

Модель Whisper скачается автоматически при первом запуске (Hugging Face), в репозитории её нет.

## Сборка .exe

```bash
pyinstaller run.py --name STTProjetV --onedir --windowed --noconfirm \
  --specpath build --distpath dist --workpath build/pyi-work --paths src \
  --additional-hooks-dir build/pyinstaller-hooks \
  --collect-all torch --collect-all ctranslate2 --collect-all faster_whisper \
  --collect-all RealtimeSTT --collect-all silero_vad \
  --hidden-import pyaudio --hidden-import pystray._win32 --hidden-import PIL._tkinter_finder
```

Готовая программа появится в `dist/STTProjetV/STTProjetV.exe`. Из-за CUDA-сборки torch (нужна,
чтобы автоопределение GPU реально работало у пользователей с видеокартой) сборка весит
несколько гигабайт — это нормально для локального AI-приложения такого рода.

`--windowed` убирает консольное окно (программа живёт только в трее). Если что-то пошло не так -
смотрите `sttprojetv.log` рядом с `.exe`, консоли для вывода ошибок в этом режиме нет.

## Настройки и словари терминов

При первом запуске рядом с программой создаются `config.json` и папка `dictionaries/` со
словарями терминов (в репозитории их нет — только примеры `config.example.json` и
`terms.example.txt`, который можно скопировать в `dictionaries/` как первый список). Всё
редактируется вручную (файлы - обычный текст, по термину на строку) или через окно настроек
(иконка в трее → «Открыть настройки»).
