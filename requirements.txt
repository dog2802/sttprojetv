# === Владельцам NVIDIA-видеокарты: сначала поставьте CUDA-сборку torch! ===
# Обычный `pip install torch` ставит CPU-сборку без поддержки CUDA. RealtimeSTT использует
# torch.cuda.is_available() для выбора устройства и при CPU-сборке ВСЕГДА переключит
# распознавание на CPU, даже если formально указано device=cuda - модель будет работать
# в 15-20 раз медленнее (это же торч также попутно даёт ctranslate2 недостающие CUDA-библиотеки
# вроде cublas64_12.dll, без него faster-whisper падает с ошибкой на GPU). Поэтому:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cu126
#   pip install -r requirements.txt
#
# (порядок важен: если сначала поставить requirements.txt, RealtimeSTT молча подтянет
# CPU-версию torch как обычную зависимость). Если видеокарты нет или она не NVIDIA - просто
# `pip install -r requirements.txt` без этого шага, приложение само перейдёт в CPU-режим.
